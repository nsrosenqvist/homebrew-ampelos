# homebrew-keel

Homebrew tap for [keel](https://github.com/nsrosenqvist/keel) — a dev-loop wrapper that adapts to your project.

## Installation

```sh
brew tap nsrosenqvist/keel
brew install keel
```

Or install in a single command:

```sh
brew install nsrosenqvist/keel/keel
```

## Updating

```sh
brew update
brew upgrade keel
```

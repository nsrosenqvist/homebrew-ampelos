# homebrew-croft

Homebrew tap for [croft](https://github.com/nsrosenqvist/croft) — the dev workspace you tend.

## Installation

```sh
brew tap nsrosenqvist/croft
brew install croft
```

Or install in a single command:

```sh
brew install nsrosenqvist/croft/croft
```

## Updating

```sh
brew update
brew upgrade croft
```
